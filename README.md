# Стратсессия Борда Holdi

Одностраничный сайт: темы сессии, индивидуальная ретро-анкета и общие итоги.

## Состав

- `index.html` — вся страница целиком: разметка, стили и скрипт в одном файле. Сборка не нужна.
- `artifact-source.html` — тот же код в виде, в котором он опубликован как артефакт в Claude (без `<html>`/`<head>`).

Рабочая версия опубликована в Claude: https://claude.ai/artifact/P9rJrXycHDaSuodrsHXRBP

## Что работает на обычном хостинге

`index.html` можно положить на любой статический хостинг (GitHub Pages, Netlify, Vercel, свой сервер).

- Вкладка «Сессия» работает полностью.
- Вкладка «Моя анкета» открывается, черновик сохраняется в браузере (localStorage), но кнопка отправки отключена.
- Вкладка «Итоги» остаётся пустой.

Причина: ответы хранятся в базе артефакта Claude, а участник определяется по аккаунту Claude. Вне Claude объекта `window.claude` нет, и страница переходит в режим «только черновик».

## Что нужно заменить, чтобы сбор ответов работал вне Claude

Всё обращение к хранилищу собрано в скрипте в конце `index.html`:

| Что | Где в коде | Чем заменить |
|---|---|---|
| Кто отвечает | `boot()`: `user.me()`, `user.can("data.write")` | своя авторизация или персональная ссылка на участника |
| Черновик участника | `flushDraft()`: документ `data/users/<id>/draft` | приватная запись на сервере (или оставить только localStorage) |
| Отправка анкеты | `submit()`: документ `responses/<id>` и копия `responses/<id>/versions/v<N>` | запись ответа и его версии в свою базу |
| Чтение всех ответов | `boot()`: `db.collection("responses").onSnapshot(...)` | загрузка всех ответов с сервера |
| Дата и место | документ `meta/session` | своё поле или текст прямо в разметке |

Подойдёт любое хранилище с документами по ключу (Firebase, Supabase и т. п.).

## Модель данных

Ответ участника, `responses/<id участника>`:

```json
{
  "answers": { "label": "Имя", "score_meetings": 4, "good_general": "…", "p_otr_score": 3 },
  "submittedAt": "2026-10-05T10:00:00.000Z",
  "firstSubmittedAt": "2026-10-05T10:00:00.000Z",
  "rev": 1
}
```

Ключи в `answers`:

- `label` — подпись участника в итогах.
- `score_<аспект>` — оценка 1–5. Аспекты: `meetings`, `progress`, `docs`, `people`, `vibe`, `entity`, `strategy`.
- `good_general`, `bad_general` — общие вопросы «что хорошо» и «что плохо».
- `good_<аспект>`, `bad_<аспект>` — комментарии по аспектам, включая `other`.
- `improve_from_bad`, `improve_missing` — что улучшить.
- `p_<проект>_score|good|bad|improve` — проекты: `otr`, `walbi`, `doto`, `knx`, `other`.

Каждая отправка дополнительно сохраняется в `responses/<id>/versions/v<rev>`, поэтому исходные ответы не теряются при правках.

## Права доступа (как настроено в Claude)

- `responses` — читают все, у кого открыт доступ к странице; чужие ответы менять может только владелец.
- `responses/<свой id>` — участник с уровнем Contributor пишет только свой ответ.
- `meta` — читают все, меняют редакторы.
- `data/users/<свой id>` — черновик виден только самому участнику.

## Как менять содержание

- Темы сессии — разметка в блоке `<ol class="agenda">`.
- Аспекты и проекты — массивы `ASPECTS` и `PROJECTS` в начале скрипта; анкета и итоги строятся из них автоматически.
- Число участников — константа `EXPECTED`.
